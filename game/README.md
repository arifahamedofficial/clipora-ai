# Neon Dash

A lightweight, responsive endless-runner arcade game built with vanilla HTML, CSS and JavaScript.

## Play locally
Open `index.html` in any modern browser.

## Controls
- **Space / Arrow Up / W** — jump
- **Tap the game / JUMP button** — jump on touch devices
- **Restart** — start a fresh run

Features: increasing difficulty, collision detection, score tracking, locally saved best score, particle effects, responsive layout. No dependencies or build step required.
